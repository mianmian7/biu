# 桌面歌词 v2 与副歌词字号

owner = Claude（osa-a1）

## 问题

1. 歌词页的罗马音/翻译写死 `text-sm`，不跟随字号；桌面歌词副行按 0.55 倍且下限 14px，设置里无法调整。
2. 桌面歌词透明窗口有残留：`html/body` 带不透明 `bg-background` 类，靠运行时内联样式覆盖；控制条使用 `backdrop-blur`；文字阴影溢出元素边界并叠加 y 方向进出场动画，透明窗口局部重绘不覆盖阴影区域；暂停时整体降到 0.82 透明度。
3. 桌面歌词功能简陋：只有字号；无颜色、描边、双行、对齐、进度高亮、播放控制；解锁后整窗是 `app-region: drag`，悬停事件无法触发。

## 方案

- 歌词页：副行字号 = 当前行字号 × 比例，跟随字号控件变化。
- 设置：新增 `desktopLyricsStyle`（嵌套对象，读取时与默认值合并）：单/双行、对齐、副行比例、显示翻译/罗马音、字体、加粗、配色方案（含跟随主题色和自定义两色）、描边/阴影/无、进度高亮、不透明度。保留 `showDesktopLyrics`/`desktopLyricsLocked`/`desktopLyricsFontSize`。
- 设置页新增「桌面歌词」标签页，含实时预览、重置样式和重置位置；原系统设置中的三项移入该页。
- 桌面歌词窗口：
  - 渲染分三层（效果层/未播放层/已播放层，已播放层用 `clip-path` 按行内进度裁切），阴影与描边留在带内边距的盒子内。
  - 进度：载荷带行起止时间、位置和同步时间戳，窗口内 rAF 插值，直接改 DOM。
  - 双行模式：当前行与下一行交错（左/右对齐）。
  - 无歌词时显示歌名与状态。
  - 解锁：手动拖动（主进程按光标轮询移动窗口），悬停显示背景与工具栏（上一首/播放暂停/下一首、字号±、换配色、单双行、翻译、罗马音、锁定、设置、关闭）。
  - 锁定：鼠标穿透 + forward，悬停显示解锁按钮，指针进入按钮时临时取消穿透。
  - 窗口高度按内容自动调整（锁定高度、宽度可调），换行不抖动（按整首歌是否有翻译/罗马音预留行）。
  - 去掉 `backdrop-blur`、进出场位移动画和暂停降透明；窗口加载时去掉 `bg-background` 类；换行后主进程 `webContents.invalidate()` 强制整窗重绘。
- IPC：统一 `desktopLyrics:command`（窗口 → 主窗口渲染进程）、`dragStart/dragEnd`、`setIgnoreMouse`、`setContentHeight`、`resetPosition`。
